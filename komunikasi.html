SISTEM KOMUNIKASI TERPADU

SECURE ON-PREMISE COMMUNICATION PLATFORM

Platform komunikasi militer berbasis on-premise (kedaulatan data penuh). Mendukung Android · iPhone · Desktop · Web dengan otentikasi MAC Address Whitelist + Device Certificate. Auto-switch antara Command Center · MANET · HF Fallback sesuai kondisi jaringan.

🚨

Kenapa Tidak Pakai WhatsApp?

Komunikasi militer via aplikasi publik (WhatsApp, Telegram) adalah celah intelijen kelas satu — metadata bocor ke server luar negeri, tidak bisa diaudit, dan tidak berfungsi saat VSAT/jaringan down. R2 Chat hadir sebagai solusi kedaulatan komunikasi.

3 MODE OPERASI

Auto-switch sesuai kondisi jaringan

🔒
COMMAND CENTER
Primary Mode
Terhubung ke Mabes AD Chat Homeserver via LAN/WAN. Semua fitur aktif: text, voice, video, file transfer.
LATENCY20–80 ms
BANDWIDTHFULL
CHANNELSText · Voice · Video
SECURITYTLS 1.3 + E2EE
📡
MANET
Contingency Mode
Mesh peer-to-peer via LoRa / WiFi Direct / Bluetooth. Store-and-forward, tetap jalan saat Command Center tidak reachable.
LATENCY200–2000 ms
BANDWIDTHLIMITED
CHANNELSText · Voice
SECURITYChaCha20-Poly1305
📻
HF FALLBACK
Emergency Mode
HF SSB 3–30 MHz via ROIP bridge. Text-only, untuk kondisi paling kritis (semua jaringan IP down).
LATENCY2–8 detik
BANDWIDTHMINIMAL
CHANNELSText only
SECURITYFrequency Hopping
